# Torrenta 1.2 — контракт доработки: трей, автозагрузка, поведение окна

Документ фиксирует **точные** имена, типы и семантику, которые одновременно
используют Tauri-бэкенд (`src-tauri`) и интерфейс (`src`). Ядро
(`crates/torrent-core`) в этой версии не меняется. Менять контракт можно только
по согласованию с Lead: любое расхождение ломает сборку у соседа.

## 1. Требования пользователя

1. В опциях приложения — запуск вместе с Windows и старт в свёрнутом в трей виде.
2. В настройках — опция «при закрытии программы крестиком сворачиваться в трей».
3. В контекстном меню правого клика пункты «Удалить торрент» и «Удалить торрент и
   файлы» дублируют друг друга. Остаётся один «Удалить торрент», а файлы
   удаляются по галочке в подтверждении: галочка стоит — стираем данные, не
   стоит — только убираем раздачу из списка.
4. Значок приложения в шапке сайдбара стоит чуть левее остальных пиктограмм —
   выровнять его в один столбец с иконками пунктов меню.
5. Названия пунктов меню должны быть выровнены по левому краю, т. е. стоять
   рядом с иконками.

## 2. Бэкенд (`src-tauri`)

### 2.1 Настройки — три новых поля

`SettingsDto` (`src-tauri/src/settings.rs`, `settings.json`, всё в `snake_case`):

```rust
pub autostart: bool,        // «Запускать при входе в Windows»
pub start_minimized: bool,  // «Запускать свёрнутым в трей»
pub close_to_tray: bool,    // «При закрытии окна сворачивать в трей»
```

Правила:

* значение по умолчанию для всех трёх — `false`; структура помечена
  `#[serde(default)]`, поэтому `settings.json` от 1.0/1.1 без этих ключей
  читается без ошибок и даёт `false`;
* `normalize()` и `to_engine_config()` не меняются: движок про эти флаги не
  знает, они управляют только оболочкой;
* новых Tauri-команд нет — флаги проходят через существующие `get_settings` и
  `set_settings`.

### 2.2 Автозагрузка (`src-tauri/src/autostart.rs`)

Автозагрузка — запись в ветке реестра текущего пользователя, без службы и без
прав администратора. Значение:

* ключ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`;
* имя значения `Torrenta`;
* данные — полный путь к текущему исполняемому файлу в кавычках
  (`"C:\...\torrenta.exe"`), чтобы путь с пробелами работал корректно.

Публичный API:

```rust
pub fn apply(enabled: bool) -> Result<(), String>;
```

* `enabled = true` — `reg add ... /f` с `std::env::current_exe()`; операция
  идемпотентна и заодно обновляет путь после обновления программы;
* `enabled = false` — `reg delete ... /f`; отсутствие значения ошибкой не
  считается;
* `reg.exe` запускается с флагом `CREATE_NO_WINDOW` (`0x08000000`), чтобы при
  старте приложения не мигало консольное окно;
* модуль только для Windows: на других платформах — no-op, чтобы код собирался;
* ошибка возвращается по-русски с деталями от `reg.exe`
  (`Не удалось включить автозагрузку: ...`) и показывается в интерфейсе тостом.

Аргументы команд собираются чистыми функциями (`add_args`, `delete_args`,
`quote_exe`), поэтому покрыты юнит-тестами, включая путь с пробелами; на Windows
есть интеграционный тест полного цикла на **пробном** имени значения
(`Torrenta__test`): запись → чтение через `reg query` → удаление. Настоящее
значение `Torrenta` тест не трогает.

### 2.3 Трей (`src-tauri/src/tray.rs`)

Значок в области уведомлений создаётся **всегда** — иначе запуск с опцией
«свёрнутым в трей» оставил бы приложение недоступным.

* идентификатор `torrenta-tray`, иконка `app.default_window_icon()`, подсказка
  `Torrenta`;
* меню: «Открыть Torrenta» (`show`) и «Выход» (`quit`);
* левый клик по значку и пункт `show` вызывают `tray::show_main(app)`:
  `show` + `unminimize` + `set_focus` для окна `main`;
* `quit` — единственный штатный выход, когда включено сворачивание по крестику;
  вызывает `app.exit(0)`;
* ошибка создания значка не прерывает запуск: пишется в `stderr`, приложение
  продолжает работать обычным окном.

Для доступа к `tauri::tray` в `src-tauri/Cargo.toml` включена фича `tray-icon`.
Меню (`tauri::menu`) отдельной фичи не требует.

### 2.4 Жизненный цикл окна

* окно `main` в `tauri.conf.json` объявлено с `"visible": false`;
* в `setup()` окно показывается, когда `start_minimized == false`; при
  `start_minimized == true` оно остаётся скрытым, а приложение живёт в трее;
* событие `CloseRequested` окна: если `close_to_tray == true` —
  `api.prevent_close()` и `window.hide()` (загрузки продолжаются); иначе окно
  закрывается штатно и приложение завершается, как в 1.1;
* при старте применяется автозагрузка: `autostart::apply(settings.autostart)`.
  Так запись в реестре обновляется после обновления программы, а при выключенной
  опции устаревшее значение удаляется. Ошибка логируется и не мешает запуску.

### 2.5 Порядок сохранения настроек

`AppEngine::apply_settings` сначала применяет автозагрузку, если флаг
изменился, и только потом пишет `settings.json`. Если `reg.exe` вернул ошибку,
настройки не меняются ни в памяти, ни в файле: галочка в интерфейсе не должна
расходиться с реестром.

## 3. Интерфейс (`src`)

### 3.1 Типы и мок-режим

* `SettingsDto` в `src/api/types.ts` получает три поля `boolean` в `snake_case`;
* в `src/api/mock.ts` дефолты и мок-сохранение отдают/принимают эти поля, чтобы
  браузерная разработка без Tauri не расходилась с бэкендом.

### 3.2 Группа «Запуск и трей» в настройках

Три чекбокса на существующем компоненте `checkboxRow`:

| Заголовок | Хинт |
| --- | --- |
| Запускать при входе в Windows | Torrenta будет добавляться в автозагрузку текущего пользователя. |
| Запускать свёрнутым в трей | При запуске окно не открывается — приложение работает в трее. |
| При закрытии окна сворачивать в трей | Крестик скрывает окно, загрузки продолжаются. Выход — через значок Torrenta в трее. |

Значения уходят в `next: SettingsDto` при сохранении. Ошибка бэкенда (например,
«Не удалось включить автозагрузку: …») показывается тостом, модальное окно
остаётся открытым.

### 3.3 Контекстное меню: одно удаление

В меню остаётся один пункт «Удалить торрент» (`danger`, иконка корзины,
разделитель перед ним). Он открывает существующее подтверждение
`confirmRemove(name, onConfirm(deleteFiles))` с галочкой «Удалить скачанные
файлы»:

* галочка стоит — вызывается `remove_torrent(id, true)`, файлы стираются с диска;
* галочка снята — `remove_torrent(id, false)`, торрент уходит из списка, данные
  остаются.

Параметр `withFiles` у `removeTorrent` и второй пункт меню удаляются.

### 3.4 Сайдбар: столбец иконок и подписи по левому краю

* значок приложения в шапке сайдбара и иконки пунктов навигации и футера стоят
  в одном столбце: совпадает оптический левый край, а не только отступ блока;
* подписи пунктов прижаты к иконкам (`flex-start` + небольшой `gap`), а не
  центрируются между иконкой и счётчиком; счётчик остаётся у правого края,
  длинная подпись обрезается многоточием;
* проверяются три состояния: обычная ширина, режим «только иконки» (узкий
  сайдбар) и компактный медиа-запрос; ресайз мышью и подсказки не ломаются.

## 4. Проверка

* `cargo test --workspace` — зелёный, включая новые тесты настроек (старый
  `settings.json` без новых ключей), аргументов `reg.exe` и полного цикла
  автозагрузки на пробном имени;
* `cargo clippy --workspace --all-targets -- -D warnings` — без предупреждений
  вообще: три старых замечания в `torrent-core` (`peer.rs`, `magnet.rs`,
  `tests/resilience.rs`) исправлены по ходу 1.2;
* `npm run build` (`tsc --noEmit` + Vite) и `npm run check:contrast` — без
  ошибок и регрессий (68 из 68 пар проходят WCAG AA);
* `.\build-windows.ps1` — установщики NSIS и MSI собираются с версией 1.2.0.

Ручная проверка собранного `torrenta.exe` 1.2.0 (все пункты ниже пройдены):

| Что проверялось | Результат |
| --- | --- |
| Обе опции выключены, `WM_CLOSE` | окно закрывается, процесс завершается — как в 1.1 |
| «При закрытии окна сворачивать в трей» включена, `WM_CLOSE` | процесс жив, окно `Tauri Window` скрыто |
| Значок в трее | в области уведомлений появляется кнопка `Torrenta`, окно вспомогательного класса `tray_icon_app` создано |
| Левый клик по значку при скрытом окне | окно снова показано и активно |
| «Запускать свёрнутым в трей» включена | при старте окно скрыто, значок в трее есть |
| Автозагрузка включена / выключена | значение `Torrenta` появляется в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` с путём к текущему exe и удаляется вместе с опцией |

Меню значка (пункты «Открыть Torrenta» и «Выход») проверено кодом и созданием
значка, но не автоматическим кликом: контекстное меню трея не удалось открыть
из тестового окружения. Выравнивание сайдбара проверено замерами DOM в браузере
в тёмной и светлой теме.
