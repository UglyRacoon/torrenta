# Torrenta 1.1 — контракт доработки интерфейса и ядра

Документ фиксирует **точные** имена, типы и семантику, которые одновременно
используют ядро (`crates/torrent-core`), Tauri-бэкенд (`src-tauri`) и интерфейс
(`src`). Менять контракт можно только по согласованию с Lead: любое расхождение
ломает сборку у соседа.

## 1. Требования пользователя

1. При добавлении `.torrent` или magnet-ссылки открывается парящее окно: выбор
   папки, список файлов торрента, отметки «что качать» (по умолчанию всё).
2. В главном окне — опция автоматического выключения ПК по завершении всех
   загрузок.
3. Левый блок навигации — по ширине содержимого (сейчас слишком широкий), ширина
   меняется мышью вплоть до режима «только иконки». Отступ между иконкой и
   подписью — маленький.
4. Контекстное меню (ПКМ по торренту) появляется в точке клика. В нём: пауза /
   возобновление, **ограничение скорости для этого торрента**, «Подробности»,
   один пункт на каталог загрузок (без дубля «Показать в проводнике» +
   «Открыть каталог загрузок»), удаление.
5. Клик по иконке паузы/возобновления в строке **не** открывает панель
   подробностей. Подробности вызываются только явно.
6. Вкладка «Файлы» в панели подробностей позволяет выбирать файлы для загрузки
   по текущему торренту.
7. Единый визуальный стиль: все выпадающие списки, поля, кнопки, меню — в одной
   стилистике; заголовок окна подстраивается под тему.

## 2. Ядро (`crates/torrent-core`)

### 2.1 Выбор файлов

```rust
/// Параметры добавления торрента.
#[derive(Debug, Clone, Default)]
pub struct AddOptions {
    /// Каталог сохранения (None — download_dir из конфигурации).
    pub save_path: Option<PathBuf>,
    /// Индексы файлов, которые нужно скачать (None — все файлы).
    /// Пустой Some(vec![]) — ошибка `EngineError::Selection`.
    pub files: Option<Vec<usize>>,
}
```

Правила:

* «Нужный кусок» (wanted) — кусок, который пересекается хотя бы с одним
  выбранным файлом. Для торрента из одного файла и «все файлы» wanted совпадает
  с полным набором — поведение 1.0 сохраняется.
* Пикер (`PiecePicker::pick`) никогда не отдаёт куски вне wanted.
* Завершение торрента — все wanted-куски на диске (даже если остальные файлы не
  выбраны). После этого состояние `Completed`/`Seeding`, как в 1.0.
* `left` в announce = суммарный размер ещё не скачанных wanted-байт.
* Смена выбора на лету: wanted пересчитывается; невыбранные куски освобождаются
  (`release`), уже скачанные остаются на диске (не удаляем файлы!). Если после
  смены выбора все wanted-куски уже есть — торрент сразу переходит в
  `Completed`, иначе (если не на паузе) — в `Downloading`.
* `FileView.selected` = файл входит в текущий выбор.

### 2.2 Снимок торрента — новые поля

`TorrentSnapshot`:

```rust
pub wanted_bytes: u64,      // сумма длин выбранных файлов
pub down_limit_kib: u32,    // действующий лимит загрузки (0 — без лимита)
pub up_limit_kib: u32,      // действующий лимит отдачи (0 — без лимита)
```

`FileView`:

```rust
pub selected: bool,
```

`progress` = «скачано wanted-байт / wanted_bytes», `total_bytes` остаётся полным
размером торрента, `downloaded_bytes`/`uploaded_bytes` — счётчики трафика.
`eta_seconds` считается по остатку wanted-байт.

### 2.3 Предпросмотр (для окна добавления)

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct PreviewFile {
    pub index: usize,
    pub path: String,
    pub length: u64,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TorrentPreview {
    pub name: String,
    pub info_hash: String,
    pub total_bytes: u64,
    pub piece_length: u32,
    pub piece_count: u32,
    pub files: Vec<PreviewFile>,
    pub trackers: Vec<String>,
}
```

```rust
impl TorrentManager {
    /// Разбор .torrent без добавления в список.
    pub fn preview_file(data: &[u8]) -> Result<TorrentPreview, EngineError>;
    /// Получение метаданных magnet-ссылки без добавления в список.
    pub async fn preview_magnet(&self, link: &str, timeout: Duration)
        -> Result<TorrentPreview, EngineError>;
}
```

`preview_magnet` ходит по трекерам из magnet и `ut_metadata`, ничего не добавляет
в список торрентов, укладывается в `timeout` (рекомендуется 25 с) и не оставляет
фоновых задач.

### 2.4 Добавление и правка

```rust
impl TorrentManager {
    pub async fn add_file_with(&self, data: Vec<u8>, opts: AddOptions) -> Result<u64, EngineError>;
    pub async fn add_magnet_with(&self, link: &str, opts: AddOptions) -> Result<u64, EngineError>;
    /// files: индексы выбранных файлов; пустой список — ошибка Selection.
    pub fn set_file_selection(&self, id: u64, files: Vec<usize>) -> Result<(), EngineError>;
    /// Лимиты конкретного торрента, КиБ/с, 0 — без лимита.
    pub fn set_limits(&self, id: u64, down_kib: u32, up_kib: u32) -> Result<(), EngineError>;
}
```

Старые `add_file`/`add_magnet` сохраняются как обёртки (`AddOptions::default()`),
чтобы не ломать существующие тесты; новые вызовы идут через `*_with`.

`EngineError` получает вариант:

```rust
#[error("не выбран ни один файл")]
Selection,
```

Действующий лимит торрента = `min` из глобального и торрентного, где 0 = «без
ограничения»: если один из них 0 — действует второй; если оба 0 — без лимита.

## 3. Tauri-бэкенд (`src-tauri`)

### 3.1 Команды

| Команда | Аргументы (camelCase на проводе) | Результат |
| --- | --- | --- |
| `preview_torrent` | `source: String` (путь к `.torrent` или `magnet:...`) | `TorrentPreview` |
| `add_torrent` | `source: String`, `savePath: Option<String>`, `files: Option<Vec<usize>>` | `u64` (id) |
| `set_file_selection` | `id: u64`, `files: Vec<usize>` | `()` |
| `set_torrent_limits` | `id: u64`, `downKib: u32`, `upKib: u32` | `()` |
| `get_auto_shutdown` | — | `AutoShutdownDto` |
| `set_auto_shutdown` | `enabled: bool` | `AutoShutdownDto` |
| `cancel_auto_shutdown` | — | `AutoShutdownDto` |

`AutoShutdownDto` (snake_case в JSON):

```rust
pub struct AutoShutdownDto {
    pub enabled: bool,
    pub pending_seconds: Option<u32>, // сколько осталось до выключения
}
```

Старые `add_torrent_file` / `add_torrent_bytes` / `add_magnet` удаляются: фронтенд
переходит на пару `preview_torrent` + `add_torrent`.

### 3.2 Автовыключение

* Настройка `auto_shutdown: bool` в `SettingsDto`, сохраняется в settings.json.
* Наблюдатель подписан на события движка. Условие запуска: настройка включена,
  в списке есть хотя бы один торрент и **ни один** не находится в
  `Queued`/`Metadata`/`Downloading` (то есть все либо `Completed`, либо
  `Seeding`, либо `Paused`, либо `Error`).
* Запуск: `shutdown.exe /s /t 60 /c "Torrenta: все загрузки завершены"`,
  событие `engine://auto-shutdown` с `{ pending_seconds: 60 }`, обратный отсчёт
  раз в секунду (последнее значение 0).
* Отмена: `shutdown.exe /a`, событие с `pending_seconds: null`. Отмена также
  происходит автоматически, если добавлен/возобновлён торрент или настройка
  выключена.
* Выключение никогда не выполняется в тестах: команда формируется функцией,
  которую можно проверить юнит-тестом.

### 3.3 Тема и заголовок окна

`set_settings` (и старт приложения) применяет тему к нативному заголовку:
`window.set_theme(Some(Theme::Dark | Theme::Light))` плюс
`window.set_background_color(...)` в цвет `#0F1319` (тёмная) / `#F2F5F9`
(светлая). Ошибки применения темы не ломают сохранение настроек.

## 4. Интерфейс (`src`, `index.html`, `scripts`)

### 4.1 Модальное окно добавления

* Открывается при выборе `.torrent`, magnet-ссылки, drag&drop и кнопке
  «Добавить».
* Содержимое: имя торрента, размер, info hash (первые символы), строка «Папка
  загрузки» с кнопкой «Обзор…», список файлов с чекбоксами (по умолчанию все),
  кнопки «Выбрать все»/«Снять все», итог «Выбрано N файлов · M из K», кнопки
  «Скачать» и «Отмена».
* Для magnet — состояние загрузки метаданных (спиннер + «Получаем список
  файлов…»); если метаданные получить не удалось, окно всё равно позволяет
  скачать торрент целиком (файлы появятся позже).
* Ошибки показываются внутри окна, окно не закрывается.
* Клавиши: Esc — отмена, Enter — скачать. Ловушка фокуса и `role="dialog"`.

### 4.2 Автовыключение в главном окне

* Переключатель в нижней строке состояния: «Выключить ПК после загрузок».
* При активном обратном отсчёте — тост/строка с «Выключение через 0:42» и
  кнопкой «Отменить».

### 4.3 Боковая навигация

* Ширина по содержимому; маркер-перетаскиватель меняет ширину мышью
  (клавиатура: стрелки), минимум 56 px — режим «только иконки» (подписи
  скрыты, у иконок `title`/`aria-label`, активный фильтр подсвечен).
* Отступ между иконкой и подписью — 8 px.
* Ширина запоминается в localStorage.

### 4.4 Контекстное меню

* Появляется в точке клика (с поправкой на границы окна), закрывается по
  Esc/клику вне/скроллу.
* Пункты: Пауза/Возобновить, «Подробности» (открывает правую панель),
  «Ограничить скорость» → подменю (Без ограничения, 64, 256, 1024, 4096 КиБ/с;
  текущий выбор отмечен галочкой), «Открыть папку загрузок», «Удалить торрент»,
  «Удалить торрент и файлы».

### 4.5 Строка торрента

* Кнопки паузы/возобновления и меню «…» не открывают панель подробностей
  (`stopPropagation`).
* Клик по строке выбирает торрент (подсветка), но панель подробностей не
  открывает; открытие — только через «Подробности», двойной клик или кнопку.

### 4.6 Вкладка «Файлы»

* Чекбокс на каждый файл, «Выбрать все»/«Снять все», счётчик выбранного размера.
* Изменение сразу вызывает `set_file_selection`; при ошибке состояние чекбоксов
  откатывается и показывается тост.

### 4.7 Единый стиль

* Собственный выпадающий список (кнопка + всплывающий список в стиле меню) для
  всех `select`-мест: сортировка, фильтр, тема, лимиты.
* Единые радиусы, рамки, тени, hover/active, скроллбары, фокус-кольца для
  кнопок, полей, меню, модальных окон, тостов, чекбоксов.
* Заголовок окна следует теме (см. 3.3).

## 5. Проверка

* `cargo test --workspace` — все тесты зелёные, включая новые:
  * ядро: wanted-куски, завершение при частичном выборе, смена выбора,
    `left` для трекера, лимиты per-torrent, предпросмотр `.torrent`;
  * бэкенд: парсинг источника (`magnet:`/путь), клампы лимитов, условие
    автовыключения, DTO;
  * `src-tauri` тесты состояния/настроек продолжают работать.
* `npm run check:contrast` — без регрессий (новые цвета только из палитры).
* `npm run build` — `tsc --noEmit` + Vite без ошибок.
* `.\build-windows.ps1` — установщики NSIS/MSI собираются.
