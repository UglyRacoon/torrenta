# Автообновление Torrenta

С 1.9.0 обновления устроены просто: приложение смотрит последний релиз в GitHub
и, если версия новее, предлагает скачать установщик из этого же релиза. Плагин
`tauri-plugin-updater` вместе с подписанным манифестом не используется — ключа
подписи у проекта нет.

## 1. Как это работает

1. Через 10 секунд после старта и дальше раз в 6 часов приложение (если
   включена настройка «Проверять обновления автоматически») запрашивает
   `https://api.github.com/repos/UglyRacoon/torrenta/releases/latest`.
2. Версия из тега (`v1.9.0` → `1.9.0`) сравнивается с версией приложения.
3. Если новая — в футере сайдбара появляется кнопка «Обновление 1.9.0».
4. Нажатие открывает окно: текущая версия → новая, размер установщика, описание
   релиза, кнопки «Позже», «Что нового» и «Скачать и установить».
5. Установщик (`*-setup.exe`, при отсутствии — `.msi`) скачивается во временный
   каталог с показом прогресса. Ссылка принимается только с `github.com`,
   размер сверяется с ответом API.
6. Установка: во временный каталог пишется `.bat`, который ждёт выхода текущего
   процесса, запускает установщик в тихом режиме (`/S` для NSIS, `msiexec /qn`
   для MSI) и снова открывает Torrenta.

Код: `src-tauri/src/update.rs` (проверка, разбор, скачивание, установка),
`src-tauri/src/commands.rs` (`check_update`, `install_update`),
`src-tauri/src/lib.rs` (фоновая проверка), `src/app.ts` (значок и окно).

## 2. Что нужно, чтобы выпустить обновление

1. Поднять версию в трёх местах: `Cargo.toml` (`[workspace.package]`),
   `package.json`, `src-tauri/tauri.conf.json`.
2. Собрать установщики: `npm run tauri build` (или `.\build-windows.ps1`).
3. Создать на GitHub релиз с тегом `vX.Y.Z` и приложить три файла:
   `Torrenta_X.Y.Z_x64-setup.exe`, `Torrenta_X.Y.Z_x64_ru-RU.msi`,
   `Torrenta_X.Y.Z_x64_en-US.msi`.
4. Убедиться, что релиз не черновик и не пре-релиз: API `releases/latest`
   возвращает только опубликованный релиз.

Никаких дополнительных действий (подписи манифеста, эндпоинта, секретов CI) не
нужно — проверка идёт по публичному API.

## 3. Ограничения

* **Нет криптографической подписи.** Сборки не подписаны сертификатом подписи
  кода, поэтому подтвердить авторство установщика технически нечем: доверие
  держится на HTTPS и на том, что релиз опубликован в репозитории проекта.
  Если понадобится подпись — нужен сертификат и подписанный манифест, то есть
  возврат к схеме `tauri-plugin-updater`.
* **Windows-only для установки.** `install_and_restart` вне Windows возвращает
  ошибку, и окно обновления честно сообщает, что установка недоступна.
* **Скачивание требует согласия.** Автопроверка только показывает значок;
  установка запускается нажатием кнопки, без фоновой подмены файлов.
* **Сеть.** При недоступном GitHub ничего не ломается: проверка просто пишет
  ошибку в журнал, значок не появляется, торренты работают как обычно.
* **Портативный режим.** Установщик ставит приложение в `%LOCALAPPDATA%`,
  поэтому портативную копию автообновление не обновляет — её нужно обновлять
  вручную, заменив exe.

## 4. Частые вопросы

**Почему в диалоге «установлена последняя версия», хотя релиз новее?**
Проверьте, что тег начинается с `v` и релиз опубликован (не черновик), а версия
в нём выше текущей. Пре-релиз (`1.9.0-beta.1`) не считается обновлением над
`1.9.0`, но считается над `1.8.x`.

**Куда скачивается установщик?**
`%TEMP%\TorrentaUpdate\`. После установки файл остаётся там же и удаляется
следующим обновлением или вручную.

**Что будет, если закрыть приложение во время скачивания?**
Файл останется недокачанным; он не запускается автоматически, а при следующей
попытке скачается заново и перезапишет его.

**Можно ли отключить проверку?**
Да: настройки → «Поведение» → «Проверять обновления автоматически». Ручная
проверка в окне «Диагностика» при этом продолжает работать.
